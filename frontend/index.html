1. Retrieval Quality Metrics

ChromaDB
Precision@K (K=5) Evaluated

Proportion of top-K retrieved document chunks that contain relevant factual statements to answer the user query.

Mean Reciprocal Rank (MRR) Ranking Metric

Evaluates how high up the first truly relevant chunk appears in ChromaDB's nearest-neighbor distance list.

Normalized Discounted Cumulative Gain (nDCG) Relevance Gradient

Measures ranking quality with higher weight given to the most relevant passages at the top of the context window.

2. Generation Quality (The RAG Triad)

LLM Assessment
Context Relevance Verified

Verifies that the retrieved context contains only information needed to answer the question without distracting noise.

Faithfulness / Groundedness Strict Prompt

Verifies that every claim made in the generated answer can be traced directly back to the retrieved context chunks.

Answer Relevance High

Checks that the response addresses the exact user question directly without hallucinating irrelevant external topics.
